# 구조와 안정성

## 책임

`App`이 서비스 수명과 WPF dispatcher를 관리합니다. `NoteService`는 메모 컬렉션, 생성·복제·삭제·창 표시를 관리하고 `Note`의 변경 알림으로 저장을 요청합니다. 메모 관리 창과 검색 뷰는 제거했습니다. 실행·재실행·트레이 더블 클릭은 저장된 메모를 모두 열며, 목록이 비었을 때만 새 메모를 생성합니다. 작은 창의 메뉴/드래그/대화상자 연결은 code-behind에 두고, 저장이나 Shell 탐색은 별도 서비스에 둡니다. DI 컨테이너와 범용 저장소 인터페이스는 사용하지 않습니다.

`DesktopWidgetService`만 Z-order, Shell 탐색과 이벤트를 담당하며 모든 P/Invoke 선언은 `Interop/NativeMethods.cs`에 모읍니다. `ScreenService`는 좌표 변환과 작업 영역 보정, `TrayService`는 NotifyIcon, `StartupService`는 HKCU Run, `SingleInstanceService`는 사용자·세션별 Mutex와 사용자 ACL Named Pipe를 담당합니다.

`AtomicFile`은 저장·백업·로그가 공유하는 내구성 있는 파일 교체만 담당하고, `StorageService`는 복구·revision·복원 트랜잭션을 담당합니다. `Json`은 구조와 스키마를 확인하고 파싱한 객체를 변환하며, `Validation`은 의미 검증을 담당합니다. 시작 처리·메뉴·IPC 수신은 역할별 함수로 분리합니다. 명시적 조합을 유지하며 DI 컨테이너나 범용 인터페이스를 추가하지 않습니다.

스냅샷은 소유 dispatcher 접근을 검사하고 메모 필드를 직접 복제합니다. 메모 수만큼 JSON 왕복을 반복하지 않으며 변경 이벤트 구독도 복제하지 않습니다. Shell foreground 이벤트는 Desktop 모드와 관계있는 경우에만 dispatcher에 전달합니다. 실행 성능의 정량 벤치마크는 수행하지 않았습니다.

## 저장 순서

1. 모델 변경을 UI dispatcher에서 관찰하고 500ms 타이머를 다시 시작합니다.
2. 타이머 또는 정상 종료 시 UI dispatcher에서 메모·설정의 독립 복사본을 캡처합니다.
3. 백그라운드 작업이 StorageService의 SemaphoreSlim을 획득합니다.
4. 이미 저장한 revision보다 오래된 스냅샷은 건너뜁니다.
5. `AtomicFile`이 같은 디렉터리의 고유 임시 파일에 UTF-8 데이터를 쓰고 `Flush(true)`합니다.
6. 기존 파일은 `File.Replace`, 최초 파일은 `File.Move`로 교체합니다. 이전 정상본은 `.bak`에 남습니다.

입력, 위치 및 크기는 같은 debounce를 공유합니다. 파일 I/O는 background Task에서 직렬 실행합니다. 일반 저장에서 notes/settings 각각은 원자적으로 교체되지만 두 파일 전체를 하나의 원자적 변경으로 묶지는 않습니다. 종료 시 UI를 잠시 비활성화하고 마지막 저장을 기다립니다. 실패하면 사용자에게 돌아갈 수 있는 선택을 제공합니다. OS 세션 종료의 저장 실패는 종료를 취소합니다.

타이머·WinEventHook·HwndSourceHook·SystemEvents·모델 이벤트·트레이·Pipe는 종료 또는 창 제거 시 해제합니다. 숨긴 메모 창도 파괴하여 에디터 및 undo 버퍼를 메모리에서 해제합니다. 숨긴 메모의 내용은 모델에 남으며 다시 표시할 때 창을 만듭니다. 자동 저장 실패는 무한 재시도하지 않고 알립니다. 다음 변경 또는 수동 저장·종료에서 다시 시도할 수 있습니다.

## 손상과 복원

지원 스키마는 v1 하나입니다. `Json.Read`의 구조/버전 경계와 `Validation`의 의미 검증을 분리했습니다. 향후 v2를 도입할 때 명시적인 v1→v2 변환을 이 경계에 추가하고 이전 버전 데이터 회귀 테스트를 유지해야 합니다. 현재 알 수 없는 버전을 추측하여 변환하지 않습니다. 날짜는 UTC ISO 8601, ID는 UUID이며 중복·누락·비정상 수치·허용 범위 밖 설정을 거부합니다.

파일이 손상되면 정상 `.bak`을 검증한 후 복구하며 손상본은 원자적으로 `.corrupt-*`에 옮깁니다. 기존 정상 `.bak`은 덮어쓰지 않습니다. 양쪽 모두 읽을 수 없거나 새 스키마이면 전체 자동 저장을 차단합니다. 원본을 빈 목록으로 덮어쓰지 않습니다.

백업 복원은 파일 크기(32MiB), 구조, 스키마, 모든 모델을 검증한 뒤 UI 편집을 정지합니다. 현재 스냅샷을 `backups`에 자동 보관하고, 기존 디스크 원본도 보존합니다. 검증된 전체 백업을 `restore.pending.json`에 먼저 원자적으로 저장한 후 두 파일을 교체합니다. 완료하면 pending 파일을 제거합니다. 중단되면 다음 실행에서 같은 전체 데이터를 재적용합니다. 적용 실패 시 일반 저장을 막아 혼합 상태를 덮어쓰지 않습니다. 자동 백업은 10개, 일별 로그는 현재 파일 포함 최대 7개(파일당 약 1MiB)로 제한합니다. 손상 및 복원 원본은 명시적으로 보존하므로 자동 삭제 대상이 아닙니다.

## 시스템과 언어

자동 백업명은 UTC 시각과 GUID를 조합해 시스템 시계 해상도·시각 역행과 관계없이 충돌을 피합니다. 보관은 수정 시각순 10개입니다. 복원 전 원본 보관은 바이트 스트림을 복사하므로 잘못된 UTF-8도 보존합니다. Sonar S3776 임계값 5를 `SonarLint.xml`에 설정하고 초과를 빌드 오류로 처리합니다. 분석기·참조 어셈블리는 빌드 전용이며 설치 파일에는 포함하지 않습니다.

자동 실행은 설치 시 HKCU Run에 등록하며 새 설정에서도 기본으로 켜져 있습니다. 앱 실행·설정 저장·복원 시 현재 설정을 적용하므로 사용자가 저장한 끄기 설정은 유지합니다. 등록 값은 인용 부호로 감싼 현재 EXE 경로이며 제거 시 등록을 지웁니다. 시스템 전체 설정은 변경하지 않습니다. 제품 표시는 Windows Stricky이며 기존 AppId·실행 파일명·데이터 경로·Run 값 이름은 업그레이드 호환을 위해 유지합니다.

한국어 `Strings.resx`, 영어 `English.resx`를 EXE에 함께 임베드합니다. 앱 시작 시 `CurrentUICulture`가 한국어이면 한국어, 나머지는 영어를 사용합니다. 언어 선택 UI는 없습니다. v1 설정·백업의 `language` 필드는 이전 파일과 왕복 호환을 위해 남겨두지만 표시 언어를 결정하지 않습니다. 설치 파일도 Windows 표시 언어에 따라 한국어/영어를 자동 선택하며, `scripts/Korean.isl`을 소스에 포함해 한국어 메시지 다운로드가 필요하지 않습니다.

제목은 헤더의 TextBox에서 직접 수정하고, 이동은 옆 손잡이에서 시작합니다. 본문은 공통 TextBox 스타일보다 우선하는 왼쪽·위 정렬을 사용합니다. 하단 왼쪽은 투명도, 오른쪽은 글자 크기이며 이름과 현재 값을 함께 표시합니다. ×·Alt+F4·작업 표시줄 닫기는 기본값 아니오인 삭제 확인을 표시합니다. 메모는 작업 표시줄에 나타나며 새 기본 모드는 Normal입니다. 기존에 저장한 표시 모드는 변경하지 않습니다. 재실행 IPC는 연결한 서버 PID에만 foreground 권한을 전달한 뒤 요청을 보내고 UI dispatcher 처리 후 응답합니다. Windows의 foreground 제한이나 명시적 Desktop 모드에서는 전면 표시가 제한될 수 있습니다.

배경색·글자색은 공통 `ColorWindow`의 색상표를 클릭·드래그하여 선택합니다. 색조 막대와 채도/명도 영역에서 RGB 슬라이더·HEX 미리보기가 함께 갱신되며, 32개 기본 색상도 제공합니다. 저장하면 모델에 반영하고 취소하면 기존 값을 유지합니다. 작은 작업 영역에서는 선택창을 스크롤할 수 있습니다. `FontWindow`에서 설치된 글씨체를 선택하고 한글/영문 견본을 확인합니다. 메모·설정의 v1 스키마에 선택 필드 `fontFamily`를 추가했으며, 기존 파일에 없으면 Segoe UI를 사용합니다. 다른 PC에 글씨체가 없으면 WPF 대체 글꼴을 사용하며 저장된 이름은 보존합니다. 알 수 없는 스키마 버전은 계속 거부합니다.

원본 아이콘은 `Assets/App.svg`, 배포용은 16~256px 프레임을 포함한 `App.ico`입니다. `scripts/generate-icon.ps1`로 재생성합니다. 앱 EXE·WPF 창·트레이·설치 EXE·제거 항목이 같은 아이콘을 사용합니다.

`VERSION`이 앱 어셈블리·설치 프로그램·CI artifact 이름의 공통 버전 소스입니다. 환경설정의 업데이트 확인은 사용자가 누를 때만 기본 브랜치의 VERSION을 읽습니다. 연결/읽기 제한 시간은 각각 8초, 본문은 64자 미만이고 숫자 3부분만 허용합니다. 메모·설정은 전송하지 않습니다. 새 버전이 있으면 수동 Build의 다운로드 페이지를 열 수 있습니다. 릴리스 자동 생성·자동 설치·자동 롤백은 추가하지 않았습니다. 배포할 VERSION 커밋으로 수동 Build를 성공시켜야 해당 설치 파일을 받을 수 있습니다.
